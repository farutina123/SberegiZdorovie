# База знаний кол-центра «СберегиЗдоровье»

Документ для операторов и ассистента: услуги, отказы, перезвоны, качество, мотивация, возрастные и прочие ограничения по клиникам. Цены, слоты, акции конкретной клиники — только по актуальному каталогу в CRM/базе; при расхождении сверять карточку клиники и фиксировать инцидент.

---

## 1. О компании и услугах

**Что делаем.** Сервис-агрегатор частных клиник Москвы и Московской области: подбираем клинику под запрос клиента, оформляем запись на диагностику и приём, поясняем условия записи, оплаты и подготовки — в рамках данных каталога.

**География.** Основной охват: Москва и МО. Города МО без партнёрских клиник в базе обрабатываются как ограничение по географии (см. раздел «Неконверсионные города»).

**Типовые категории услуг (для ориентира оператора).**

- **Консультации специалистов** — первичный/повторный приём; длительность и нужность направления уточнять по карточке клиники и специальности.
- **Лабораторная диагностика** — забор биоматериала, сроки готовности, подготовка (натощак и т.д.) — строго по описанию услуги в каталоге.
- **Инструментальная диагностика** — УЗИ, рентген, КТ, МРТ, ЭЭГ, денситометрия и др.; для каждого вида уточняются противопоказания, подготовка, длительность, ограничения по весу/возрасту/имплантам — по карточке клиники и услуги.
- **ЭЭГ (ориентир по форматам).** Стандартная — около 60 минут с учётом подготовки; ЭЭГ дневного сна — около 2 часов; ночной (длительный) мониторинг — около 8–10 часов. Детский возраст и наличие услуги для детей — только из каталога.
- **Денситометрия.** Рентгеновская (DXA) и УЗ-метод; зоны исследования (позвоночник, тазобедренный сустав, предплечье и т.д.) — по услуге в каталоге.
- **МРТ.** Мощность аппарата (Тесла), ограничение по весу, совместимость с имплантами/клапанами — различаются по клиникам; не домысливать, сверять карточку.

**Медицинские рекомендации.** Оператор не назначает лечение, не интерпретирует результаты исследований и не заменяет врача. Можно называть доступные услуги, общую информацию о подготовке и записи, если она есть в каталоге/регламенте.

**Выбор «лучшей» клиники.** Уточнять критерии: район/метро, бюджет, дата и время, метод или модель аппарата, срочность, возраст пациента, ограничения по здоровью (без диагностики «на лету»). Без критериев — честно сказать, что объективного «лучшего» без вводных нет, и собрать вводные.

## 2. Правила перезвонов клиентам

1. **Цель перезвона.** Завершить цикл запроса: подтвердить запись, уточнить детали, предложить альтернативы после мониторинга слотов или ответа клиники.
2. **Сроки.** Перезвон в обещанное окно времени обязателен. Если слот или ответ клиники не получены к сроку — перезвонить с обновлением статуса (не молчать до «готовности всего» без промежуточного контакта, если клиенту обещали связь).
3. **Количество попыток.** Минимум две попытки дозвона в разное время (если регламент смены не задаёт иное). После безуспешных попыток — статус в CRM, SMS/мессенджер при разрешении канала связи.
4. **Фиксация.** В карточке: дата и время перезвона, результат (дозвон/не дозвон), договорённости, следующий шаг.
5. **Приоритет.** Срочные медицинские сценарии по внутреннему регламенту смены — выше очереди перезвонов по «мягким» подбором (без обещаний срочности вне возможностей клиник).
6. **Не дублировать спамом.** Не назначать более одного активного перезвона на один и тот же запрос без причины; при эскалации на другую линию — проверить историю контактов.

## 3. Правила постановки отказов (общие)

1. **Отказ только по факту.** Основание — отсутствие услуги/географии/слота в каталоге, несоответствие правилам клиники, запрос вне компетенции линии или нарушение политики (персональные скидки без оснований и т.п.).
2. **Классификация.** Указывать тип отказа в CRM: географический, ценовой, временной, «нет услуги», «нецелевой запрос», «отказ клиента», «риски/безопасность», «данные не предоставлены» — по утверждённым у супервизора значениям.
3. **Коммуникация.** Коротко объяснить причину без спора; где возможно — альтернатива (другая клиника, другой район, другой формат услуги).
4. **Неконверсионные отказы.** Фиксировать отдельным признаком/подтипом согласно инструкции отдела аналитики (для корректной статистики конверсии).
5. **Сомнительные кейсы.** Если неясно, конверсионный ли отказ или какой подтип — не гадать; запросить подтверждение у старшего смены и затем проставить код.

## 4. Перечень неконверсионных отказов (типовые коды)

Использовать актуальную номенклатуру CRM; ниже — смысловые категории для единого понимания.

| Категория | Пример формулировки для клиента |
|-----------|----------------------------------|
| География вне охвата | Работаем только по Москве и МО; в указанном населённом пункте партнёров нет. |
| Нет клиники/услуги в городе МО | В этом городе МО в базе нет партнёрских клиник под запрос. |
| Услуга не оказывается партнёрами | Запрошенного метода/исследования нет в каталоге при данных ограничениях. |
| Объективное отсутствие слота в горизонте | При полном переборе доступных партнёров слотов нет (фиксировать период поиска). |
| Нецелевой или недобросовестный запрос | Запрос не связан с записью, мошенничество, агрессия без готовности к диалогу по услуге. |
| Отказ от предоставления минимальных данных | Нельзя оформить запись без ФИО/телефона и обязательных полей клиники. |
| Медицинские противопоказания по правилам клиники | Клиника отказывает в записи по своим критериям — оператор не оспаривает, предлагает альтернативу при наличии. |

## 6. Чек-лист контроля качества (разговор)

Оценочный список для самопроверки и супервизии (да/нет):

1. Приветствие и представление линии при необходимости.
2. Уточнены услуга, локация или готовность к поездке, желаемые даты.
3. Даны условия из каталога (цена, подготовка, длительность) без выдуманных деталей.
4. Нет медицинских назначений и интерпретации результатов.
5. Отработаны возражения по скрипту политики (скидки только по акциям каталога).
6. При ограничениях по возрасту/весу/противопоказаниям — отсылка к правилам клиники или уточнение у клиники, без гарантий «точно подойдёт».
7. Запись или перезвон зафиксированы в CRM, статус корректен.
8. При конфликте данных между источниками — эскалация старшему смены.
9. Персональные данные — минимально необходимый объём для записи.
10. Тон: без спора, без давления, без обещаний невозможного.

## 7. Правила расчёта премии (ориентир)

Точные коэффициенты, веса KPI и пороги утверждаются **отделом мотивации/HR и финансовым отделом** ежеквартально или при смене модели. Для оператора ориентир:

- **База.** Конверсия в записанный и подтверждённый визит из обрабатываемых лидов за период.
- **Качество.** Минусовые корректировки за ошибочную информацию клиенту, жалобы подтверждённые QA, нарушение регламента персональных данных.
- **Дисциплина.** Соблюдение смен, опоздания, необоснованные споры — по внутреннему регламенту.
- **Штрафные кейсы.** Заведомо ложные обещания цены/наличия услуги, подделка статусов в CRM — вне премии и по дисциплинарным нормам.

При любых спорных начислениях — обращение к руководителю смены с выгрузкой из CRM.

## 8. Ограничения по возрасту и особым условиям (ЭЭГ, МРТ и др.)

**Общее правило.** Возрастные минимумы/максимумы, допуск детей, необходимость седации, ограничения по весу для томографа, вопросы с имплантами и кардиостимуляторами — **только из карточки конкретной клиники и услуги**. Если в каталоге нет явной строки — сообщить клиенту, что условие нужно подтвердить у выбранной клиники, и не подтверждать запись до ответа клиники.

**ЭЭГ.** Указать формат исследования и типичную длительность из базы знаний; возраст ребёнка сверить с фильтром услуги «детская ЭЭГ» в каталоге.

**МРТ/КТ.** Сверить весовой лимит аппарата, необходимость контраста, противопоказания — по карточке; при сомнении клиента направить на прямое уточнение в регистратуру клиники перед финальной записью.

**Разные лимиты веса в разных клиниках.** Для каждой клиники использовать только её карточку в каталоге; не усреднять лимиты «на глаз» и не переносить ограничение одной клиники на другую. Если в источниках противоречие по параметрам аппарата — зафиксировать и эскалировать старшему смены по регламенту.

**УЗИ/ренген у детей.** Наличие педиатрического профиля и возрастные правила — из каталога.

## 9. Акции и скидки

- Скидки действуют **только** если активная акция отображена в каталоге/карточке услуги или клиники.
- Персональные скидки «просто потому что попросили» не предоставляются.
- Нельзя суммировать акции, если это прямо запрещено условиями промо в каталоге.
- Если клиент настаивает на скидке без основания — вежливый отказ и предложение вариантов с действующими акциями или альтернативных клиник.

## 10. Куда эскалировать нестандартные запросы

| Ситуация | Куда |
|----------|------|
| Разные цены/условия в источниках, сбой каталога | Старший смены + техническая поддержка/контент-команда каталога по внутреннему каналу |
| Жалоба с требованием письменного ответа, претензия к качеству услуги в клинике | Старший смены → отдел качества / клиентский сервис по регламенту |
| Юридические угрозы, запрос персональных данных третьих лиц | Старший смены → юридический блок по инструкции |
| Изменение политики оплаты, спецусловия контрактных клиентов | Отдел продаж / аккаунт-менеджеры B2B |
| Вопросы начисления премии, графика, больничные | HR / руководитель операционного блока |
| Опасность для жизни и здоровья, острые симптомы | Не консультировать; рекомендовать скорую помощь/неотложку по общему правилу; эскалация старшему смены |

## 11. FAQ: нестандартные ситуации и процессы

**Вопрос:** Клиент настаивает на записи в город МО из списка «неконверсионных», но готов приехать в Москву — это отказ?  
**Ответ:** Нет. Фиксируете отказ по первоначальному городу как географический, затем оформляете новый подбор по Москве или доступным точкам МО с клиниками.

**Вопрос:** Пациент просит назначить лечение по симптомам.  
**Ответ:** Объясняете, что линия записи не заменяет врача; предлагаете запись к профильному специалисту или диагностику из каталога по его запросу.

**Вопрос:** В двух документах разная цена на ту же услугу в той же клинике.  
**Ответ:** Не озвучивайте цену как окончательную; эскалация старшему смены и сверка с актуальной карточкой каталога, клиенту — честный статус «проверяем».

**Вопрос:** Клиент требует скидку как «постоянному пациенту клиники», но акции нет.  
**Ответ:** Скидка только по акции в каталоге; можно предложить клиники с действующими промо или альтернативный формат услуги.

**Вопрос:** Нужна запись «сегодня вечером», слотов нет ни у одного партнёра.  
**Ответ:** Фиксируете временной неконверсионный отказ за период поиска; предлагаете ближайшие доступные даты и подписку на перезвон при освобождении слота, если это регламентировано.

**Вопрос:** Клиент отказывается давать телефон или ФИО.  
**Ответ:** Без минимальных данных запись невозможна; объясняете причину; при отказе — неконверсионный отказ «данные не предоставлены».

**Вопрос:** Запрос из другого региона (не Москва и не МО).  
**Ответ:** Сообщаете про охват Москва/МО; подбор вне региона не ведёте; тип отказа — география вне охвата.

**Вопрос:** Клиент просит обещать результат исследования или «что всё нормально».  
**Ответ:** Такие формулировки запрещены; только нейтральное описание услуги и организационные условия.

**Вопрос:** Родственник записывает пожилого человека без его согласия на линии.  
**Ответ:** Уточняете полномочия и контакт пациента при необходимости клиники; при сомнениях — политика клиники и эскалация старшему смены.

**Вопрос:** Клиент угрожает судом из-за отказа клиники принять по противопоказаниям.  
**Ответ:** Спокойный тон, фиксация факта; передача старшему смены и отделу качества/юристам по процедуре.

**Вопрос:** Нужна справка или возврат оплаты за уже оказанную услугу.  
**Ответ:** Организационные и финансовые вопросы после визита решает клиника; соединяете или переводите на канал клиентского сервиса/партнёрской линии по регламенту.

**Вопрос:** Запрос на корпоративную программу или оплату от работодателя.  
**Ответ:** Направляете в отдел продаж/B2B или даёте контакт по корпоративному блоку согласно актуальной таблице контактов.

**Вопрос:** Клиент просит «самую дешёвую МРТ без разницы где».  
**Ответ:** Фильтруете каталог по цене и ограничениям пациента (вес, контраст, возраст); озвучиваете условия выбранных клиник без скрытых доплат из головы.

**Вопрос:** Для ЭЭГ ребёнку нет возраста в каталоге ни в одной клинике запроса.  
**Ответ:** Не придумываете возраст; сообщаете, что по фильтру нет опций и нужна эскалация контента или ручной запрос в клиники через старшего смены.

**Вопрос:** Клиент хочет суммировать две акции на одну услугу.  
**Ответ:** Только если это явно разрешено условиями промо; иначе одна акция или полная стоимость по каталогу.

**Вопрос:** Оператор ошибся и назвал неверную цену, клиент уже едет.  
**Ответ:** Немедленно старшему смены и клиенту — коррекция с извинениями; дальше по политике компенсаций отдела качества.

**Вопрос:** Нужен перевод на англоязычного оператора.  
**Ответ:** По внутреннему роутингу языковой линии или обратный звонок назначенным языковым агентом — если сервис предоставляется; иначе честно сообщить о ограничении.

**Вопрос:** Клиент просит подобрать клинику с «гарантией записи без очереди».  
**Ответ:** Формулировки «гарантия без очереди» избегаете; описываете реальные условия записи и времени приёма из каталога.

**Вопрос:** Запрос на услугу, которую компания не продвигает, но клиент нашёл название в интернете.  
**Ответ:** Если услуги нет в каталоге — не создаёте ожиданий; неконверсионный отказ «нет услуги» или передача на расширение каталога через супервизора.
