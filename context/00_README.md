# Контекст (тестовые данные)

Это тестовый набор материалов для проверки ассистента. Содержимое вымышленное, только для разработки.

Состав:
- `faq.md` — ответы на частые вопросы
- `regламент_оператора.md` — правила общения/эскалации/нестандартные ситуации
- `политики.md` — скидки/оплата/отмена/возвраты
- `отказы_и_возражения.md` — неконверсионные отказы и допустимые формулировки
- `каталог_клиник.json` — небольшой каталог клиник (Москва) с параметрами
