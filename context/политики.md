# Политики (тест)

## Скидки и промо
- Скидки применяются только если в каталоге/продукте указана активная акция.
- "Персональные скидки по просьбе" не предоставляются.
- Если клиент просит скидку без основания: отказ + предложение альтернатив (другая клиника/время/услуга) в пределах каталога.

## Оплата
- Оплата по умолчанию: в клинике (карта/наличные) — см. карточку клиники.
- Предоплата возможна только если указана в условиях клиники.

## Отмена/перенос записи
- Отмена/перенос возможны по правилам клиники (см. карточку клиники).
- Если правила не указаны: "В контексте нет данных: условия отмены в клинике" и эскалация на старшего смены.

## Персональные данные
- Нельзя просить/хранить лишние персональные данные.
- Для записи: ФИО, телефон, дата рождения (если требуется клиникой), услуга, желаемое время.
