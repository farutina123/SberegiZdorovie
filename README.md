# Telegram-ассистент кол-центра «СберегиЗдоровье»

## Что это
Telegram-бот для операторов. Бот отвечает через LLM, **строго** следуя системному промпту (не фантазирует, опирается только на подложенный контекст) и хранит **последние 10 сообщений** диалога.

Команды:
- `/start` — приветствие и краткая инструкция
- `/reset` — очистить историю диалога (последние 10 сообщений)

## Быстрый старт (Windows / PowerShell)

1) Установите зависимости:

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

2) Создайте `.env` рядом с `.env.example` и заполните переменные:
- `TELEGRAM_BOT_TOKEN`
- `OPENAI_API_KEY`
- (опционально) `OPENAI_BASE_URL`, `OPENAI_MODEL`

3) Положите данные (FAQ/регламенты/каталог) в папку `context/` (txt/md/json).

4) Запустите бота:

```bash
python -m bot.main
```

## Как устроен контекст
Бот читает все файлы из `CONTEXT_DIR` (по умолчанию `context/`) и “набивает” их в системный запрос как **единственный источник истины**.

Если контекст слишком большой, он будет обрезан до `CONTEXT_CHAR_LIMIT` по символам.
